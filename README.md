## Text-to-Speech Mode

| Command | Effect |
|---|---|
| text to speech mode / tts mode / enable tts | Verity speaks back whatever she hears instead of a canned "I don't know" |
| reset / normal voice / disable tts / stop tts | Back to canned responses |

## Awareness

| Command | Effect |
|---|---|
| am i tagged / am i it / check tag status | Reports your tag status |
| are we in a lobby / in a room / lobby status | Reports your lobby status |

---

**Note:** the bare word "reset" is a catch-all for disabling TTS mode, but it loses to more specific phrases like "reset gravity" or "reset player size" when you say one of those instead — each command is scored on its own, independent of the others.
